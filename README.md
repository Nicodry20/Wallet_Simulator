# 💰 Wallet Simulator API

API REST para simular operaciones bancarias como transferencias, recargas, pagos de impuestos y gestión de contactos. Desarrollada con Node.js, Express y PostgreSQL.

---

## 🚀 Tecnologías

- Node.js + Express
- PostgreSQL (hosteado en Render)
- JWT para autenticación
- Bcrypt para encriptación de contraseñas
- Helmet para seguridad
